Управление портфолио

Для входа нужен токен GitHub аккаунта renatspaceprince. Он действует в этой вкладке до её закрытия или обновления.

Как получить токен

Откройте создание fine-grained token. Введите название «Панель портфолио», выберите срок действия. В Repository access укажите Only select repositories → r.s.portfolio-2026. В разделе Permissions откройте вкладку Repositories и нажмите + Add permissions. Найдите и добавьте Contents. В появившейся строке Contents выберите Read and write. Нажмите Generate token, скопируйте токен и вставьте его в поле «Токен GitHub» на этой странице панели.
